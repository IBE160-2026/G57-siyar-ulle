# Product Brief – Moldiz

G57

## Gruppemedlemmer
- Siyar
- Ulle

## Produktidé

Moldiz er en KI-basert studieassistent som skal hjelpe studenter med å lære og forstå fagstoff på en enklere måte.

Brukeren kan skrive inn eller lime inn fagtekst, notater eller annet pensum. Applikasjonen bruker kunstig intelligens til å analysere teksten og kan blant annet lage sammendrag, forklare vanskelige konsepter og generere spørsmål eller quiz.

Målet er å gjøre det lettere for studenter å repetere fagstoff og teste sin egen forståelse.

## Problem

Studenter må ofte lese store mengder pensum og notater. Det kan være vanskelig å vite hvilke deler av teksten som er viktigst, og det tar tid å lage egne sammendrag og øvingsspørsmål.

Moldiz skal gjøre denne prosessen enklere ved å bruke KI til å bearbeide fagstoffet automatisk.

## Målgruppe

Hovedmålgruppen er studenter på høyskole og universitet.

Applikasjonen kan være nyttig for studenter som ønsker å:

- repetere pensum
- få enklere forklaringer på vanskelige temaer
- lage sammendrag av fagstoff
- teste kunnskapen sin med spørsmål og quiz

## Viktigste funksjoner

### 1. Sammendrag
Brukeren kan lime inn tekst, og KI lager et kort sammendrag av de viktigste punktene.

### 2. Forklaring av fagstoff
Brukeren kan be KI forklare vanskelige deler av teksten på en enklere måte.

### 3. Generering av spørsmål
KI kan lage spørsmål basert på teksten brukeren har lagt inn.

Eksempler:
- flervalgsspørsmål
- korte spørsmål
- spørsmål med fasit

### 4. Quiz
Brukeren kan gjennomføre en quiz basert på fagstoffet og få tilbakemelding på svarene.

## Bruk av kunstig intelligens

KI er en sentral del av Moldiz og skal brukes til å:

- analysere tekst
- identifisere viktig informasjon
- lage sammendrag
- forklare kompliserte temaer
- generere spørsmål
- lage quiz og svar

Applikasjonen kan bruke en språkmodell gjennom et API.

## Teknologi

Vi vurderer å bruke:

- Python
- Git og GitHub
- Streamlit
- et API for en KI-språkmodell

Python brukes til hoveddelen av applikasjonen, mens Streamlit kan brukes til å lage et enkelt brukergrensesnitt.

## Minimum Viable Product (MVP)

Den første versjonen skal minimum kunne:

1. La brukeren skrive inn eller lime inn tekst.
2. Sende teksten til en KI-modell.
3. Generere et sammendrag.
4. Generere noen spørsmål basert på teksten.
5. Vise resultatet til brukeren.

## Mulig videreutvikling

Hvis vi har tid, kan vi legge til:

- opplasting av PDF-filer
- flashcards
- flere typer quiz
- vanskelighetsgrader
- poengsystem
- lagring av tidligere notater
- støtte for flere språk

## Mål for prosjektet

Målet er å utvikle en fungerende applikasjon der kunstig intelligens er en sentral del av løsningen.

Prosjektet skal også gi oss erfaring med:

- Python-programmering
- bruk av KI-modeller og API-er
- Git og GitHub
- testing
- brukergrensesnitt
- kvalitetssikring av KI-genererte svar
